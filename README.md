# RI1_ComparacaoDeVingadores
Projeto da matéria de Programação Orientada a Objetos (POO) focado em JavaScript. Este exercício (RI 1) cria objetos para representar heróis Vingadores e Thanos, armazena-os em um Array e utiliza estruturas de repetição (for) para comparar seus atributos (velocidade, força e resistência), identificando onde um personagem 'vence' o outro.
